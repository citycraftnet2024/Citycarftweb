Java Edition Anleitung

  1. Minecraft Java Edition öffnen
  2. Auf Multiplayer klicken
  3. Server hinzufügen auswählen
  4. citycraft.net eingeben
  5. Server beitreten

Bedrock Edition Anleitung

  1. Minecraft Bedrock öffnen
  2. Auf Server klicken
  3. Server hinzufügen auswählen
  4. citycraft.net eingeben
  5. Verbinden und spielen

Befehle Vorschau

Plot Befehle

/plot claim

Beansprucht ein freies Grundstück.

/plot home

Teleportiert dich zu deinem Plot.

/plot auto

Gibt dir automatisch ein freies Plot.

/plot trust NAME

Gibt Spielern Rechte auf deinem Plot.
